> 版本 1.1 | 2026-11-21 | 适用数据库: `finance_project`（MySQL 8.0.14+）

## 1. 数据表结构

| 表名 | 用途 | 主键 | 关键字段 |
|------|------|------|----------|
| `trade` | 交易流水（每笔成交） | `trade_id` | account_id, symbol, direction, quantity, price, amount, trade_time, trade_date |
| `position` | 日频持仓快照 | (account_id, symbol, trade_date) | pre_qty, qty, cost_price |
| `market_data` | 日频行情 | (trade_date, symbol) | close_price, pre_close |
| `position_adjust` | 非交易持仓变动 | `adjust_id` | account_id, symbol, ex_date, adjust_type, qty_delta, cash_flow, cash_income, remark |

**数据关系**：`position` 与 `trade` 通过 (account_id, symbol, trade_date) 关联；`position` 与 `market_data` 通过 (symbol, trade_date) 关联；`position` 与 `position_adjust` 通过 (account_id, symbol, ex_date) 关联。

> `position_adjust` 为空时，对账与盈亏口径和只有买卖成交的版本完全一致。

## 2. T+1 对账口径

### 2.1 对账公式

```
理论持仓 = 上日持仓(pre_qty) + 当日净成交(net_trade) + 非交易持仓变动(qty_delta)
对账差异 = 系统持仓(qty) - 理论持仓
```

其中：
- `net_trade = ΣBUY.quantity - ΣSELL.quantity`（按 account_id + symbol + trade_date 聚合）
- `qty_delta` 来自 `position_adjust`，覆盖送股、转增、拆股、缩股、配股等非买卖成交的持仓变化

**差异模式**（`diff_pattern`）：

| 模式 | 判定 | 含义 |
|------|------|------|
| 新发 | 前一日 diff = 0，当日 diff ≠ 0 | 根因日，优先排查 |
| 持续 | 前后两日 diff 同号 | 同一笔错账跨日未修正 |
| 反转 | 前后两日 diff 异号 | 隔日冲正；也可能是“次日自愈”的造数雷 |

### 2.2 差异分类

| 差异符号 | 分类 | 含义 |
|----------|------|------|
| diff > 0 | **多记** | 系统记录的持仓比成交推算的多，可能重复录入 |
| diff < 0 | **漏记** | 系统记录的持仓比成交推算的少，可能遗漏录入 |
| diff = 0 | **一致** | 对账通过 |

### 2.3 示例

```
上日持仓 500 股 → 当日买入 200 股, 卖出 100 股
→ net_trade = +100
→ 理论持仓 = 500 + 100 = 600
→ 若系统记录 qty=500 → diff=-100（漏记 100 股）
```

## 3. 市值口径

### 3.1 公式

```
持仓市值(MV) = qty × close_price
```

- `qty` 取自 `position.qty`（本日盘后持仓）
- `close_price` 取自 `market_data.close_price`（当日收盘价）
- 单位：元（人民币）

> 上日市值 = `pre_qty × 上一可用收盘价`（用 LATERAL 子查询取当前日期之前最近一条行情，停牌或数据缺失时不会取错日期）。

### 3.2 账户总市值

```
账户总市值 = Σ(各标的 qty × close_price) ，按 account_id + trade_date 聚合
```

## 4. 盈亏口径

### 4.1 当日盈亏 (Daily P&L)

```
当日盈亏 = (当日市值 - 上日市值)
         - (买入金额 - 卖出金额 + 非交易资金流)
         + 现金分红
```

其中：
- `上日市值 = pre_qty × 上一可用收盘价`；停牌时自动沿用最近收盘价
- `非交易资金流` 来自 `position_adjust.cash_flow`（配股缴款为正、退回为负）
- `现金分红` 来自 `position_adjust.cash_income`，属于投资收益，不是外部现金流

**推导逻辑**：
- 上日持有 pre_qty 股，市值 MV_{t-1}
- 今日买入 b 股 (支出 b×p_b)，卖出 s 股 (收入 s×p_s)
- 今日收盘持有 qty_t 股，市值 MV_t
- 盈亏 = MV_t - MV_{t-1} + s×p_s - b×p_b - 配股缴款 + 现金分红

> **关键解释**：买入是新增投入，卖出是资金抽出，二者都不计入盈亏；现金分红是投资收益，计入盈亏。送转/拆股只改变股数，不改变市值，也不产生盈亏。

### 4.2 浮动盈亏

```
浮动盈亏 = qty × (close_price - cost_price)
```

- `cost_price` 按**加权平均法**计算：每次买入后重新计算 `(旧持仓×旧成本 + 买入量×买入价) / 新持仓`
- 卖出不改变剩余持仓的成本价
- 仅对 `qty > 0` 的记录计算

### 4.3 示例

```
上日: 持有 600519 共 200 股, cost=1480, close=1500
  MV_yesterday = 200 × 1500 = 300,000

今日: 买入 100 股 @1510, 收盘 1520
  buy_amt = 100 × 1510 = 151,000
  MV_today = 300 × 1520 = 456,000

当日盈亏 = (456,000 - 300,000) + (0 - 151,000)
        = 156,000 - 151,000
        = 5,000 元

验证: 
  - 旧持仓 200 股从 1500→1520，赚 200×20 = 4,000
  - 新买入 100 股从 1510→1520，赚 100×10 = 1,000
  - 合计 = 5,000 ✓
```

### 4.4 公司行为口径

| 类型 | 持仓 | 成本价 | 除权除息参考价 | 盈亏影响 |
|------|------|--------|----------------|----------|
| 送股/转增 | qty += q × ratio | 总成本不变，每股成本摊薄 | 前收 / (1 + ratio) | 0 |
| 拆股 | qty += q × ratio | 同上 | 同上 | 0 |
| 配股 | qty += q × ratio | 加权加入配股缴款 | (前收 + ratio × 配股价) / (1 + ratio) | 缴款是外部资金流，不计入盈亏 |
| 现金分红 | 不变 | 不变 | 前收 − 每股派息 | 分红计入投资收益 |

`position_adjust` 字段含义：
- `qty_delta`：非交易持仓变动（送转/拆股为正，缩股为负）
- `cash_flow`：外部资金流（配股缴款为正）
- `cash_income`：投资收益（现金分红）

模拟数据会在除权日按上表调整价格路径，因此公司行为本身不会制造收益率跳变；对账时 `qty_delta` 也已被计入理论持仓，不会被误报成差异。

## 5. 收益率口径

### 5.1 日收益率（三种口径）

| 口径 | 公式 | 用途 |
|------|------|------|
| **TWR**（时间加权） | 当日盈亏 / 上日市值 × 100 | 策略绩效评估；剔除申购赎回/买卖对收益的干扰 |
| **Modified Dietz** | 当日盈亏 / (上日市值 + 0.5 × 净资金流) × 100 | 成交在盘中发生时的近似；比 TWR 更贴近实际资金暴露 |
| **简单口径**（v1 旧口径） | 当日盈亏 / (上日市值 + 买入金额) × 100 | 兼容旧看板；买入越多，收益率被稀释得越厉害 |

其中 `净资金流 = 买入金额 - 卖出金额 + 非交易资金流`。

**为什么旧口径不是 TWR**：TWR 的分母是**期初**资本，新增买入属于外部现金流，只能影响分子，不能进分母。旧口径把买入金额加进分母，实际上更接近"资金加权"的近似，且对买入、卖出的时点假设不一致（买入按日初、卖出按日末）。

**累计 TWR**：

```
累计 TWR = Π(1 + r_t) - 1
```

账户级视图用 `EXP(SUM(LN(1 + r_t)))` 链式计算；上日市值为 0 的日期（新开仓/空仓）不计入链式乘积。

> **边界处理**：
> - 新开仓当日上日市值 = 0 → TWR 返回 NULL，另给 `new_position_return_pct`（相对买入金额）
> - 清仓当日上日市值 > 0 → 正常计算，收益率反映卖出日盈亏
> - 停牌 → 沿用最近可用收盘价，`stale_days` 标记行情滞后天数
> - 真正缺价（此前完全没有行情）→ `v_daily_return` 不产生该行，另用数据质量查询 D2 检出

> **资金加权收益（MWR/XIRR）**：反映投资者实际体验，需按现金流日期求 IRR，SQL 不适合直接计算；当前未提供，可在 Python 中基于 `trade` + `position_adjust.cash_flow` 计算。

### 5.2 浮动收益率

```
浮动收益率(%) = (close_price - cost_price) / cost_price × 100
```

## 6. 异常检测维度

| 检测项 | 方法 | 阈值 | 输出 |
|--------|------|------|------|
| 对账差异 | SQL 直接比对 diff ≠ 0 | 任何差异 | 差异清单 CSV |
| 收益率跳变 | 全样本 z-score（按 account+symbol） | z > ±2.5 | 跳变清单 CSV |
| 持仓为负 | SQL 检查 qty < 0 | 任何负数 | 负持仓清单 CSV |

### 6.1 z-score 计算

```
z = (x - μ) / σ
```
其中 μ、σ 为同一 (account_id, symbol) 历史全部日收益率的均值和标准差。

## 7. 数据边界与假设

| 项目 | 假设 |
|------|------|
| 时间范围 | 2026-08-01 ~ 2026-10-31（约 65 个交易日） |
| 标的范围 | 600519(茅台)、000858(五粮液)、601318(平安)、000333(美的)、600036(招行) |
| 账户范围 | acc_001, acc_002, acc_003 |
| 价格模型 | 几何布朗运动，年化漂移 4%~12%，年化波动 20%~30% |
| 分红/拆股 | 模拟数据包含 5 笔公司行为，生成 13 条 `position_adjust`：10送2、每股派1.5元、10配3@30元、1拆2、10送1 |
| 交易成本 | 不包含佣金、印花税 |
| T+1 结算 | 假设当日成交当日到账（实际 A 股 T+1 交收，此处简化） |
| 周末/节假日 | 仅跳过周末，不考虑法定假期 |
