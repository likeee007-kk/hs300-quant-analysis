# 设计说明：沪深300多源数据与 z-band 策略回测

这份文档记录“为什么这么做”，而不是重复 README 的“怎么做”。面试时如果被追问，优先讲这里的取舍。

## 1. 项目目标

用一条可复现的流水线回答三个问题：

1. 日频行情与月频 PMI 如何对齐，才能既保留信息又不引入未来函数？
2. 均线类特征对次日收益到底有没有预测力？
3. 如果没有稳定 alpha，这个策略还有什么价值？

结论是：**5 个特征的 IC 都不显著；策略的价值在于下跌市空仓、控制回撤，而不是可交易的 alpha。** 这个结论被写进 README 的 TL;DR，避免把回测收益包装成实盘预期。

## 2. 数据源与口径

- 行情：AKShare `stock_zh_index_daily("sh000300")`，沪深300**价格指数**，不含分红。因此基准收益偏低，长期比较时应意识到这一点。
- 宏观：AKShare `macro_china_pmi()` 的制造业 PMI。官方 PMI 在当月最后一天发布，所以把“2024年03月份”解析为 `2024-03-31`，再用 `merge_asof(backward)` 对齐到交易日。
- 区间：2021-01-04 至 2026-11-13，共 1,420 个交易日、71 个自然月。

## 3. 时间对齐与防前视

`merge_asof(direction="backward")` 的语义是：对每个交易日，取“日期不晚于该交易日”的最近一条 PMI。这样不会把下个月才发布的 PMI 用到本月。

需要特别说明的是：官方 PMI 在**当月最后一天**发布，所以月末最后一个交易日可能看到当月 PMI；如果月末是周末，则要等到下一个交易日。测试 `tests/test_alignment.py` 校验了“PMI 在一个自然月内最多切换一次，且只在该月最后一个交易日切换”。

防前视还有两道闸：

- 预测目标 `fwd_ret = ret.shift(-1)` 只用于分析，**不写入** `hs300_features.csv`；
- 回测信号在 t 日收盘生成，仓位 `shift(1)` 后从 t+1 日生效。

## 4. 特征与冗余诊断

候选特征覆盖趋势、动量、波动、量能、宏观五个维度。冗余处理分两步：

1. **相关性诊断**：`ma5` 与 `ma20` 相关约 0.99，保留更平稳的 `ma_ratio = ma5/ma20 - 1`；`dif` 与 `ma_ratio` 相关约 0.82 且 IC 更弱，剔除。
2. **VIF 复核**：对最终 5 个特征计算 VIF，均低于 5。

注意：VIF 在这里是**复核**，不是“逐个剔除直到 VIF<5”。如果机械地按 VIF 删除，可能把策略核心变量删掉。

## 5. IC / ICIR 检验

- 主检验：`feature(t)` vs `ret(t+1)`，同时给 Pearson、Spearman 和 t 值。
- 稳健性：对 5/20/60 日 horizon 用**非重叠抽样**（`iloc[::h]`）重算 IC，避免重叠窗口让 t 值虚高。
- 稳定性：120 日滚动 IC，并计算 ICIR = mean(rolling IC) / std(rolling IC)。

结果是所有 |IC| ≤ 0.05，所有 |t| < 1.96，没有特征达到 5% 显著性。这个“没有结论”的结论本身就是项目价值：它阻止了把噪声当 alpha。

## 6. 回测设计

- 信号：对 `ma_ratio` 做 252 日滚动 z-score；`z > +0.5` 入场，`z < -0.5` 离场，中间维持原仓位。滞回带的作用是减少均线贴合时的反复开平。
- 成本：单边 5bp（佣金 + 冲击成本），按 `|Δ仓位| × 5bp` 在调仓日计提；同时输出零成本对照。
- 样本切分：前 70% 为 IS（2021-01-29 至 2025-02-20），后 30% 为 OOS（2025-02-21 至 2026-11-13）。参数按经济含义预先固定，参数网格只展示 IS 敏感性，**不用 OOS 挑参数**。
- 指标：累计/年化收益、年化波动、夏普、最大回撤、Calmar、胜率、暴露度、交易次数、年化换手、年化成本。

结果：全样本 +1.99% vs 基准 -25.35%，最大回撤 -25.50% vs -45.60%；OOS +12.39%、夏普 0.76、最大回撤 -6.92%。但只有一次切分，样本量不足以证明可重复性。

## 7. 已知限制

1. 单一指数、单一区间、一次 IS/OOS 切分，结论对市场状态敏感；
2. 所有特征不显著，策略不是 alpha；
3. 参数网格没有稳定占优组合，结果对参数敏感；
4. 以日收盘价成交、只做多、0/1 满仓，未建模滑点分布、涨跌停、停牌与资金容量；
5. 价格指数不含分红，5bp 单边成本是保守估计。

## 9. 如果重做一次

- 把单指数扩展成多标的横截面，用面板数据检验因子的稳健性；
- 增加 walk-forward 而不是一次 70/30 切分；
- 把 MySQL 层接入调度（如 Airflow/cron），做 T+1 增量更新与数据质量告警；
- 对交易成本做敏感性分析（5/10/20bp），并建模涨跌停不可成交。
